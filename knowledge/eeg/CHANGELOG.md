# EEG knowledge system changelog

## 2.0.0-draft — 2026-08-29

- 将领域概念、术语、认识状态、消费端中立知识卡、推理边界、报告策略、来源和 schema 物理分层；
- 将检索排序/组合策略迁到知识库外的声明性影子配置，避免领域知识绑定 RAG 消费方式；
- 明确知识库永远不是患者事实、标签、模型分数或临床金标准；
- 将模型名称、损失函数、项目数据映射、训练策略和自由提示词排除出活动知识；
- 采用五态认识模型，并把旧 `unknown` 设为需要解析的摄入别名；
- 将“最早头皮可见改变”“头皮电图定位候选”“非侵入性 SOZ 假设”“临床/侵入性 SOZ”
  和 EZ 分开；
- 加入 claim→患者证据与 claim→知识来源两条独立追踪链；
- 保留 `knowledge_base.jsonl` 作为现有程序的兼容来源摘要入口；
- 将 1.0 长文降级为历史迁移设计稿。

## 1.0.0 — 2026-08-28

- 初始 LearningEEG/标准/教材综合长文和 25 条来源摘要。
